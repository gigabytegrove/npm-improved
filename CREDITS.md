# NPM Improved — Origins and Credits

NPM Improved is independently developed and maintained by **Gigabyte Grove**, a technology-connected homestead that builds and shares software to solve practical problems.

## Upstream foundation

NPM Improved originated as a fork of [Nginx Proxy Manager](https://github.com/NginxProxyManager/nginx-proxy-manager), an MIT-licensed open-source reverse proxy management project. We acknowledge and appreciate its original developers and contributors for the foundation on which this project began.

The current project has undergone extensive independent development in its UI, configuration safety, high availability, node synchronization, recovery tooling, and operational management. NPM Improved is **not an official Nginx Proxy Manager release** and is not affiliated with or endorsed by the upstream maintainers. Issues involving NPM Improved should be reported to [this project](https://github.com/gigabytegrove/npm-improved/issues), not automatically to the upstream project.

A historical fork relationship does not imply that every current component originated upstream, or that upstream maintainers are responsible for subsequent development.
